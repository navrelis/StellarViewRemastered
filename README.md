# Stellar View Remastered

Stellar View Remastered is a maintained fork of [Stellar View](https://github.com/Povstalec/StellarView) by Povstalec, a Fabric mod that improves the night sky while keeping the Vanilla feeling. The original mod is also available on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/stellarview) and [Modrinth](https://modrinth.com/mod/stellarview). This fork is released under the MIT licence, like the original.

Current version: 1.1.0. See `CHANGELOG.md` for the history.

## Clouds

Version 1.1.0 adds Stellar View's own cloud renderer. It replaces the flat Vanilla clouds with soft, translucent cumulus in Vanilla style, built from many overlapping puffs.

- Colours follow the time of day: white by day, warm orange toward the sun at sunrise and sunset with violet on the far side, dark blue at night (brighter at full moon), and a silver lining around the sun
- Rain and thunder make the clouds grow, merge and darken smoothly, without popping; lightning flashes light them
- Far clouds shrink and melt into the fog; near the camera they fade softly when you fly through them
- Slow wind drift
- Follows the Vanilla cloud setting: Off = no clouds, Fast = flat cloud sheets, Fancy = full volume. Works with Fabulous graphics
- Generated on a background thread; at default settings about 13k puffs, a couple of draw calls and around 0.2 MB of cloud data
- No telemetry, no network access

Compatibility:

- With an Iris shader pack active, the pack's own clouds are used
- If the standalone Better Clouds mod is installed, Stellar View leaves the clouds to it
- Dimensions with their own sky or cloud renderer (Aether, Twilight Forest, Nether, End) are left unchanged
- Works with Sodium (replaces Sodium's clouds) and honours Sodium Extra's cloud height

Settings: Stellar View config screen, Clouds page, or the section "Clouds Config" in `config/stellarview-client.toml`. All settings apply live.

| Setting | Range | Default |
|---|---|---|
| Enabled | on/off | on |
| Cloud distance | 100-350 % of render distance | 200 % |
| Coverage | 0-100 % | 50 % |
| Cloud size | 50-200 % | 100 % |
| Thickness | 0-96 blocks | 40 |
| Height offset | -128 to 256 blocks | 0 |
| Opacity | 10-200 % | 100 % |
| Drift speed | 0-1000 % of Vanilla | 100 % |
| Brightness | 50-150 % | 100 % |
| Sunset glow | 0-150 % | 100 % |

Cloud look inspired by Better Clouds by Qendolin; Stellar View's renderer is an independent implementation.

## What Remastered changes

- Vanilla-like moon cycle (option, on by default): the Moon stays opposite the Sun and no longer shows in the daytime sky
- Steps aside for Iris shader packs: while a shader pack is active the shader draws the sky; Stellar View comes back when shaders are turned off, without a restart (option, on by default)
- Bug fixes, among them:
  - Crash with a static sky in the End
  - Config sliders that could not be set
  - Meteor chance options that had no effect
  - Sun staying dim after a visit to the End
  - Constellation stars drawn twice
  - Sky sweeping across a time jump
  - Far objects placed wrongly by coordinate rounding
  - GPU buffers leaking on every resource reload

  The full list is in `CURSEFORGE.md` (changelog 1.0.0).
- Less work per frame: the mod's own memory allocation per frame on the render thread went from about 159 KiB to about 39 KiB at night and from about 124 KiB to about 27 KiB by day, measured in a large modpack with a sky-only view.
- Meteors follow the configured chance (default 10 %), so they are much rarer than in Stellar View 0.5.3

## Features

- Milky Way Galaxy
- Brighter Stars
- Independent Moon movement (optional; the Vanilla-like cycle is the default)
- Light interference (Stars appear dimmer if you're standing near a light source)
- Location-based Sky rotation
- Supernovae
- Shooting Stars
- Meteor Showers
- Custom Skybox support
- Planets and apparent retrograde planetary motion
- Soft, voluminous clouds from Stellar View's own renderer (see Clouds)
- Can be used as a dependency for other mods

The mod is purely client-side and does not need to be installed on a server. It does not change anything on the server; all changes are visual.

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.16.14 or newer
- Fabric API
- Mod Menu is recommended for the config screen
- Optional: Iris, Sodium and Sodium Extra (see Clouds for how the clouds behave with them)
- Client-side only

## Configuration

The config screen is available through Mod Menu. The config file is `config/stellarview-client.toml`. The two options added by Remastered:

- "Vanilla Moon Cycle": key `client.overworld.vanilla_moon_cycle`, default true
- "Disable With Shaders": key `client.disable_with_shaders`, default true

## Building

This mod uses the [Fabric](https://fabricmc.net/) modding API. Build it with:

```
gradlew build
```

The jar is written to `build/libs`.

The logo is generated by `py logo/make_logo.py` (needs Pillow).
